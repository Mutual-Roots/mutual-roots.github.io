Fordiverse rclone

What is it? Fordiverse rclone is a private Google OAuth client (desktop app) owned by Simon Moritz Reichard. It is used with the open-source tool rclone to access the operator's own Google Drive from their own computers: uploading, downloading, synchronizing and backing up their own files.

Who is it for? Only Simon Moritz Reichard. It is not a public service: there is no sign-in, download or other users.

Which data? Only files and metadata in Simon Moritz Reichard's own Google Drive (permission: https://www.googleapis.com/auth/drive). Data stay on the operator's own devices; no sharing, sale or advertising. Use of Google API data follows the Google API Services User Data Policy, including the Limited Use requirements. Details: Privacy policy, Fordiverse rclone section.

Revoke access: https://myaccount.google.com/permissions

Contact: mutual.ford.perfect@gmail.com
