fordiverse-rclone

Was ist das? fordiverse-rclone ist ein privater Google-OAuth-Client (Desktop-App) von Simon Moritz Reichard. Er wird mit dem Open-Source-Programm rclone benutzt, um von eigenen Rechnern auf das eigene Google Drive zuzugreifen: eigene Dateien hochladen, herunterladen, synchronisieren und sichern.

Für wen? Nur für Simon Moritz Reichard selbst. Es ist kein öffentlicher Dienst; es gibt keine Anmeldung, keinen Download und keine weiteren Nutzerinnen oder Nutzer.

Welche Daten? Nur Dateien und Metadaten im eigenen Google Drive von Simon Moritz Reichard (Berechtigung: https://www.googleapis.com/auth/drive). Die Daten bleiben auf eigenen Geräten; keine Weitergabe, kein Verkauf, keine Werbung. Die Nutzung von Daten aus Google-APIs folgt der Google API Services User Data Policy, einschließlich der Limited-Use-Anforderungen. Details: Datenschutzerklärung, Abschnitt fordiverse-rclone.

Zugriff widerrufen: https://myaccount.google.com/permissions

English

fordiverse-rclone is a private OAuth client (Google-OAuth-Client (Desktop-App)) used by Simon Moritz Reichard together with the open-source tool rclone (https://rclone.org) to access Simon Moritz Reichard's own Google Drive: uploading, downloading, syncing and backing up own files. It is not a public service and has no sign-up, no download and no other users. It accesses only files and metadata in Simon Moritz Reichard's own Drive (scope: https://www.googleapis.com/auth/drive). Data stays on Simon Moritz Reichard's own devices and is never shared, sold or used for advertising. Use of information received from Google APIs adheres to the Google API Services User Data Policy, including the Limited Use requirements. Privacy policy: https://mutual-roots.github.io/datenschutz/
